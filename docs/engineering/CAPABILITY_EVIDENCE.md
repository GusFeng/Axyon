# F02 initial capability evidence contract
The existing historical inventory is not the public Discord API denominator. The runtime evidence projection records effect, minimum actor permission, configured AI/automation eligibility, preliminary risk, and separate implementation/access/validation dimensions. All registered entries remain not-certified until integration evidence exists. The twelve categories are an initial taxonomy, not an exhaustive endpoint enumeration. Official reference index: https://docs.discord.com/developers ; reviewed application command surface: https://docs.discord.com/developers/docs/interactions/slash-commands . Gateway, resource, SDK, policy, eligibility and error coverage remain to be reviewed individually.
